# @oneix/shared

TypeScript types and constants shared across `apps/storefront`, `apps/api`,
and `apps/zendesk-app`, so the three apps can't silently disagree about the
shape of a `Cart`, `Coupon`, or `Order`. Kept in sync with
[../../docs/data-model.md](../../docs/data-model.md) and
[../../docs/api-spec.md](../../docs/api-spec.md).
