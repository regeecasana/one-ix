# @oneix/shared

TypeScript types and constants shared between `apps/web` and
`apps/zendesk-app`, so the two apps can't silently disagree about the
shape of a `Cart`, `Customer`, or `Order`. Kept in sync with
[../../docs/data-model.md](../../docs/data-model.md) and
[../../docs/api-spec.md](../../docs/api-spec.md).
